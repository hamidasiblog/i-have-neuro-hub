# 概要

## ハブの役割

ハブは、共通のプリセットと型を置く層です。
決まりの本文は、それぞれのスキルのリポジトリにあります。ハブは決まりを写しません。

## 層

層は hub・NMA・voice の3つです。

### hub

共通のプリセットと型を置きます。

### NMA

### voice

声で思い出す出口です。
