# preset-1

軽いプリセットの1つ目です。[重なりマップ](../overlap-map.md) から、少ない数だけを選びました。
決まりの本文は写していません。本文は、基準の i-have-adhd の `SKILL.md` にあります。

## 選んだもの

決まりは7つです。

| 番号 | 中身 | 本文の場所（i-have-adhd） |
| --- | --- | --- |
| 1 | セッションの終わりまで続く | Persistence |
| 2 | 手順は番号つき。1手順に1動作 | Rules 2 |
| 3 | 最後に次の一手を1つ書く | Rules 3 |
| 4 | 脇道を出さない | Rules 4 |
| 5 | いまの状態を毎回書く | Rules 5 |
| 6 | エラーは原因と直し方を淡々と書く | Rules 8 |
| 7 | 慣用句・たとえを使わない | Pre-send check 5 |

例外は2つです。この2つは、いつも上の7つより上です。

| 中身 | 本文の場所（i-have-adhd） |
| --- | --- |
| 壊す操作の前に確かめる | When to break the rules 2 |
| ハーネスの指示が上 | When to break the rules 6 |

i-have-asd と i-have-tbi の中の対応する場所は、重なりマップの「3つに共通」にあります。

## 選んだ理由

- 3つのスキルに共通のものだけを選びました。重なりマップの「向きが逆のところ」の4つは入っていません。
- 3つのあいだで細かい差があるところは、基準の i-have-adhd の本文に合わせました。
- Rules 2 の「いちばん少ない手順にする」は i-have-adhd だけの部分です。本文を写さないので、そのまま入ります。外すかどうかは未決です。

## 外したもの

| 外したもの | 理由 |
| --- | --- |
| 最初の行は動作（adhd Rules 1） | 向きが逆 |
| 前置き・まとめ・結びを書かない（adhd Rules 10） | 向きが逆 |
| 時間や量は具体的な単位で（adhd Rules 6） | 2つだけに共通 |
| 何が動くようになったかを書く（adhd Rules 7） | 2つだけに共通 |
| リストは5個まで（adhd Rules 9） | adhd だけ |
| adhd の例外 1・3・4・5 と、Pre-send check 1〜4 | 3つに共通でない |
| asd の4つの形（Pattern 1〜4） | asd だけ |
| asd と tbi に共通のもの（質問は1つ、選択肢は2〜3個、切り替えの知らせ、止まれる場所、など） | 2つだけに共通 |
| tbi の持ち越しメモ、全部書き直す、目的の1行、など | tbi だけ |
| 診断・治療の助言をしない（asd・tbi の What this is not） | 2つだけに共通 |

1つずつの一覧は、重なりマップの「2つだけに共通」「1つだけ」「向きが逆のところ」にあります。
